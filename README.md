Descrição do projeto
Apploja é um aplicativo de loja desenvolvido com React Native + Expo. Ele permite:

navegar entre telas usando React Navigation
exibir produtos por categoria
visualizar detalhes de cada produto
fazer requisições HTTP com Axios
usar uma tela simples de login/acesso
Resumo ideal para GitHub
Apploja é um app de loja móvel em React Native com Expo, que mostra produtos por categoria, exibe detalhes de cada item e usa Axios para consumir uma API backend. O projeto inclui navegação entre telas e uma tela de login simples.
